# M227 Production Report

M227 builds on the M225/M226 harbor flow by making shipyard, repair, market and arsenal readable as distinct world-space service anchors. Each service is attached to the existing harbor module socket, has a different silhouette before color, carries a stable authored-replacement slot and is explicitly visual-only.

No new service authority, pathfinder, collision, economy or combat logic was introduced. The existing docked service strip and repair purchase path remain authoritative. Static QA is covered by the M227 regression test plus the complete historical pytest suite. Native Godot/Android/Desktop/Web visual QA remains required.
