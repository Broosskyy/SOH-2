# M243 — Wanted & Bounty Foundation

M243 implements the V3.8 authority-safe Wanted/Bounty vertical foundation without pretending that the missing online PvP service exists.

Player Wanted is a risk/reward state, not a permanent punishment. V3.8 triggers are represented explicitly: high honor, kill streak, bounty actions, Risk-Sea dominance and official world bounties. A qualified hunter defeat or future server rule can resolve/reduce the state.

Bounties support NPC, Admiral, Monster and later Player targets. Reward dimensions are modeled, but M243 intentionally defines no reward amounts, Wanted thresholds, decay timers or PvP modifiers because V3.8 reserves final values for playtests.

The client is read-only for player Wanted, PvP kill qualification, anti-farming, Honor and reward settlement. Repeat-target farming, alt feeding, power-gap farming, respawn camping, dogpiling, logout exploits, trade-kill patterns and AFK targets are server verdict inputs.

The Command Deck exposes Wanted and published bounty contracts only when authoritative data exists. No fake local Wanted score, player bounty or reward is generated.
