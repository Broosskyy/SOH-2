# M246 — Achievements & Collections Foundation

M246 converts the V3.8 achievement/collection placeholder into an authority-safe runtime and Command Deck surface. Collections cover Ship Collection, Admiral Codex, Monster Codex, World Discovery, Event Collection and Cosmetics. Achievements cover Combat, PvP, Monster, Admirals, Guilds, Events, Exploration, Economy, Collection and Progression.

Online progress, completion, ownership, claims, receipts and permanent profile showcase are server authoritative. The client may cache and present a monotonic server snapshot, but cannot infer completion or grant rewards. Offline/local preview exposes only the canonical categories.

Reward families follow the master: Fame, Titles, Cosmetics, Items and small progression rewards. Final thresholds and quantities remain content/balance values and are not invented in M246.
