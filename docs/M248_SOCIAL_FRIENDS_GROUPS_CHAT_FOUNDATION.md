# M248 — Social / Friends / Groups / Chat Foundation

Binding basis: V3.8 §§504–510. M248 adds an authority-safe client replica for Friends, small Fleet Groups, Chat channels, public Profile/Inspect data and Safety/Moderation.

Normal groups target about five players initially, but the size stays configurable. Group credit counts damage, effective healing, shield restoration, cleanse and objectives; overheal and AFK proximity do not count. Chat channels are World/Global, Region, optional Map, Group, Guild, Alliance, Whisper and System. Chat never owns gameplay authority.

Block, Mute, Report, rate limiting, spam protection and moderation logs are live server requirements. Client/local saves cannot authoritatively mutate friendships, group membership/ready state, chat delivery, moderation or group contribution. Mail remains a separate future service.
