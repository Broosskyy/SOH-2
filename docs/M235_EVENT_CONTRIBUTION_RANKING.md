# M235 — Event Contribution, Ranking & Reward Eligibility

M235 extends the M233–M234 online-ready event presentation path with a client-replica contract for personal/group contribution, authoritative ranking, qualification tiers and reward eligibility.

The client never computes authoritative ranks, never marks itself eligible and never grants event rewards. Connected operation consumes monotonic server snapshots. The existing local EventRuntime score is exposed only as a clearly marked preview fallback and does not infer rank or eligibility.

Presentation is intentionally compact and temporary so the sea chart remains dominant. No damage, range, reload, navigation, collision, spawn, event-phase or reward values change.
