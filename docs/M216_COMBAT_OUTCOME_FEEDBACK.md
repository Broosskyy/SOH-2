# M216 — Combat Outcome & Feedback

M216 deepens the visible combat loop without changing authoritative gameplay values. The five gameplay master references and the M213 high/wide oblique camera remain the composition lock.

Broadside fire now carries a stronger short muzzle-blast silhouette, hull hits receive a brief world-space confirmation ring, and sinking ships create a compact smoke/fire/debris read that remains visible at sea-chart zoom. Player defeat receives an explicit centered HUD state while the existing sink/respawn process runs. Respawn adds a temporary world-space protection ring tied visually to the already-existing protection duration. Enemy loot drops receive a short drop burst so the player can see where salvage appeared before sailing to collect it.

All M216 additions are presentation-only. Damage, range, reload, movement, collision, respawn timing, protection timing, loot values and pickup radius are unchanged. Mobile, web and desktop share the same world/combat presentation; only responsive interface sizing may differ.
