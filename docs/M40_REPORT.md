# M40 — Early Combat Arsenal + Mobile Selection Polish

- PL1-5 now exposes eight cannon ammunition types from the start.
- Effects are mechanically distinct: baseline, burst, slow, armor penetration, burn DoT, venom DoT, temporary armor break, spectral vulnerability mark.
- Mobile ammo picker lists the full arsenal and remains responsive in landscape/portrait.
- Added original utility item **Abyssal Veil**: 8s target-denial, 45s cooldown, breaks when firing.
- Harbor merchant can restock all early ammunition and Veil charges.
- Standard Iron Shot emergency restock remains the anti-softlock baseline.
- No broadside/angle damage introduced.
- Static source validation performed; no native Godot 4.7.2 binary was available in this environment.
