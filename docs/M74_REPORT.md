# M74 — PL1–5 Content Cadence + Encounter / Loot Feedback Polish

M74 is a presentation and content-density pass grounded in the existing beginner vertical slice.

- Added a PL1–5 content-cadence contract that maps existing movement/combat/salvage/harbor/monster/elite/admiral/trial systems to a clearer learning sequence without changing BeginnerRules tuning.
- Neutral beginner NPCs now expose a short visual ALARM window after the player provokes them. EncounterRelation remains the relation truth.
- Target HUD and world nameplates share the same encounter presentation layer for neutral/provoked/elite/admiral/monster labels.
- Monster/admiral arrivals now have replaceable VFX slots and procedural fallback feedback.
- Loot collection gets tier-aware visual feedback and prepared uncommon/rare/epic/legendary chest model slots.
- Pirate Trial completion gets a short mobile-readable completion chip; progression/reward mechanics are unchanged.
- Added eight text-free encounter/loot UI assets, eight more model slots and nine VFX slots.
- Added an M74 mobile feedback budget and production wave.

No combat balance, loot values, beginner goals or online/backend authority were invented. Native Godot 4.7.2 parser/runtime/device QA remains pending.
