# M196 — Regional World Identity

The Master Concept requires named regions/maps rather than a technical 1/1-style grid, with meaningful exploration and regional escalation. M196 therefore makes region id an input to deterministic chart composition while explicitly excluding platform/device class from gameplay-world generation.

The same stable sector and content version now resolve the same gameplay geometry on Android, iOS, Web and Desktop. Regional differences come from macro-anchor transforms, route rhythm and POI semantics. Rendering quality can still reduce particles, shadows, LOD or decorative dressing, but cannot remove islands, encounters, POIs or routes.
