# M197 — Regional Encounter Zones

M197 converts encounter placement from chart-wide random scatter into deterministic regional combat geography on the canonical 360×360 named charts.

Patrols, normal monsters and admirals now receive separate regional anchor families. A clear travel corridor is reserved from ordinary patrol/monster spawning so every chart keeps a readable sailing route; this does not create invulnerability and does not alter combat rules once an encounter is engaged. Islands remain the only normal hard navigation blockers. Ships, NPCs, monsters, bosses and players remain movement-nonblocking actors.

The layout is platform-neutral. Mobile, Web and Desktop receive the same encounter anchors, spawn pool authority, spawn counts, rewards and combat math. Only interface presentation may differ responsively.

This milestone is static-verified only; native Godot runtime/device QA remains required.
