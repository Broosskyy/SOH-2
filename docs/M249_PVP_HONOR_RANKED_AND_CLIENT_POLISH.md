# M249 — PvP / Honor / Ranked + Continuous Client Polish

Binding basis: V3.8 V1.5 §§313–354 and the standing visual/HUD master locks.

M249 promotes the competitive client boundary from FOUNDATION to PARTIAL without pretending the local prototype is a live PvP backend. It adds a monotonic server replica for PvP zone/flag state, protection, Honor, Ranked/Division, queue, combat timer, modifiers and settlement presentation. The client cannot mutate PvP vulnerability, Honor, MMR/Rank Points, match result, combat timer, anti-farm verdicts or competitive rewards.

The same milestone begins the new continuous-polish rule: future feature milestones also improve existing client quality when safe. M249 applies restrained Command Deck open/card transitions, denser responsive touch-card typography, server-only PvP HUD status chips and a subtle presentation-only primary-fire readiness pulse. No gameplay values, collision, navigation, camera, map content, spawn caps or balance are changed.

Permanent locks preserved: mobile Tap-to-Sail, camera joystick camera-only, lower-right primary attack, round gameplay minimap, rectangular full sea chart, identical world/gameplay across platforms, selected target as strongest combat cue and no Broadside/angle damage.
