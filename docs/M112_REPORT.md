# M112 — Physical PL16–20 World Expansion

The PL16–20 contracts from M111 are now physically registered in the sea-map runtime. The grid expands from 4×4 to 5×5 while all existing coordinates remain unchanged. The connected path is PL15 Hunter's Verge -> PL16 Cursed Wake -> PL17 Black Lantern Sea -> PL18 Gilded Grave -> PL19 Admiral's Scar -> PL20 Crown of Ash.

Cursed Dominion has a runtime region contract, Cursed biome encounter fallback, regional NPC/Admiral production slots, harbor/island slots and deliberately irregular island composition choices. Only one sector content root remains loaded at once, so the expansion does not load five maps simultaneously.

PL12+ credited NPC/Elite/Admiral sinks now grant local Silver chart fragments. This is prototype tuning; the full Silver Bonusmap scene remains pending and the fragments do not bypass Pirate Trials.

Cursed Hunter ship targets can advance Hunter objectives. The true Cursed Serpent/Ghost Whale creature slots remain prepared but are not falsely presented as finished creature encounters.

Native Godot/mobile QA remains pending.
