# M187 · Harbor Local Service Boundary

The harbor is a real Seekarte POI. It may host local services and explicitly authored harbor-only quests. It is not the parent navigation for Werft, ships, equipment, ordinary quests or other global meta systems.

## Global anywhere
Ships / Shipyard, Equipment / Loadouts, Itemshop, ordinary Quests, Events, Guild, Rankings, Achievements, Logbook and Progression.

## Local by explicit opt-in
Dock visit, repair, local supply market, regional vendor/crafting, harbor NPC, `requires_harbor=true` / `quest_scope=harbor` quests, and harbor event hooks.

M186 honest navigation remains the routing basis: only an actually existing port can be targeted; no teleport or fabricated target is created.
