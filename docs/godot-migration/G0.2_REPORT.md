# G0.2 Final Report

Baseline: `134b4b4`. Engine: Godot 4.7.2, GL Compatibility.

## Result: PASS

G0.2 passes its milestone criteria with explicitly limited hardware evidence.
The presentation baseline, mobile input decision, responsive native QA, fresh
exports and automated regressions are complete. Physical Mobile Web and Android
hardware remain `NOT TESTED`; this is an allowed, documented outcome rather
than inferred hardware validation.

## Completed evidence

- Perspective Naval production camera locked at FOV 35, height 560, back 360,
  lateral -58, target `(0, 12, -52)`, zoom 0.55–1.38.
- Kraken presentation locked at scale 52, yaw 180, waterline 20.5 and wake
  stern local `+Z` 58.
- Native LOW/HIGH captures at 1280×720, 1920×1080 and 2400×1080 were generated
  and reviewed, including eight headings, zooms, islands, POI and mobile layout.
- QA's north/south HUD contact was corrected by changing
  `ui_anchor_height` 59→68 and gap 8→10.
- Mobile semantics were resolved to tap destination, left camera-pan joystick
  and pinch zoom; desktop retains WASD direct steering.
- Authored tropical/storm/abyss WebP presentations were copied from existing
  public assets. Small/medium scenes use storm/tropical over retained 3D proxy
  landmasses; no final authored island/harbor GLBs exist.
- Kraken measurements and an explicit LOD/texture strategy were recorded.

risk. The transition to explicit dependencies is documented in

## Hardware status

Evidence vocabulary is VERIFIED, EMULATED, EXPORT_ONLY and UNAVAILABLE.

- Native desktop LOW/HIGH multi-aspect capture review: **VERIFIED**.
- Desktop Web at all three aspect ratios: **VERIFIED**; WebGL2 booted, captures
  were non-black and no fatal console errors were reported.
- Mobile Web touch emulation: **EMULATED**; all three sizes booted with five
  touch points. Black CDP captures are `CAPTURE_UNRELIABLE`.
- Windows export: **VERIFIED** by timed native boot smoke; 103,072,768 bytes.
- Android export: **EXPORT_ONLY**; 48,688,433-byte APK.
- Mobile Web hardware: **PARTIAL — BOOTS, BLACK CANVAS AFTER SPLASH** on first
  HTTPS Android run; GLES shadow mismatch fixed and export regenerated, retest
  pending.
- Android hardware: **UNAVAILABLE / NOT TESTED**; no device was detected and
  `adb` was unavailable.
- iOS: **UNAVAILABLE / NOT TESTED**; no suitable host was available.

A black emulated capture while engine/runtime evidence remains live is
**CAPTURE_UNRELIABLE**. It is not reported as a visual hardware PASS.
