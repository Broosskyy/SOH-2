## Architecture change (G0.5)

- **Removed from runtime:** `GameplayHUD` / `gameplay_hud.gd` as scene owner (file retained deprecated).
- **New owner:** `GameplayPresentationRoot` (`gameplay_presentation_root.gd`) with `PresentationLayout` zone rects.
- **Layout model:** Anchored zones only — no full-screen HUD containers.
