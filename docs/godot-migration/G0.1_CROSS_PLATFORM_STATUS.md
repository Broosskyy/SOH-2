## Portable foundation

- No Windows-only runtime path is used.
- Save data remains under `user://profiles`.
- Keyboard/touch inputs converge on `PlayerCommand`.
- Camera and HUD use Godot APIs available on all targets.
- Gameplay rules, movement plane and catalog are shared across quality tiers.
- Generated exports, `.godot` cache, APK/EXE and QA captures remain untracked.
