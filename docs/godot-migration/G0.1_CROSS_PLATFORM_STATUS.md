## Portable foundation

- No Windows-only runtime path is used.
- Save data remains under `user://profiles`.
- Keyboard/touch inputs converge on `PlayerCommand`.
- Godot's G0.1 touch joystick steers the ship; V20.3.2 Web uses its left
  joystick for camera pan and click/tap navigation. This semantic gap is
  explicit and must be resolved before input parity is declared.
- Camera and HUD use Godot APIs available on all targets.
- Gameplay rules, movement plane and catalog are shared across quality tiers.
- Generated exports, `.godot` cache, APK/EXE and QA captures remain untracked.

## Local preview

- Desktop QA HTTP: `http://127.0.0.1:8061/index.html`
- Local HTTPS: `https://127.0.0.1:8062/index.html`
- LAN Mobile HTTPS at validation time: `https://192.168.178.144:8062/index.html`
- Server: `npm run serve:godot:web` (HTTP on `127.0.0.1:8061`, HTTPS on
  `0.0.0.0:8062` with a self-signed dev certificate).

Plain HTTP on a LAN IP is not a Secure Context and cannot boot Godot 4.7 Web on
physical mobile browsers. Use the HTTPS endpoint above for phone hardware tests.

LAN addresses are environment-specific and must be rediscovered for later runs.
