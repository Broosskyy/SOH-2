# G0.1 Existing Godot Client Audit

Baseline: `main` at `e950596` (V20.3.2 feature commit `d6c4de5`).
Project: existing `godot/` client; no replacement project was created.

## Classification

| System | Decision | Audit result / G0.1 action |
| --- | --- | --- |
| Player movement | KEEP + UPDATE | `CharacterBody3D`, X/Z velocity, `-Z` forward, Y lock and bounds were correct. Input sampling moved to `PlayerInputSource`; movement now consumes `PlayerCommand`. |
| Camera | KEEP + UPDATE | Fixed world-space oblique follow, bounded zoom and overview/shake contracts retained. Added three calibrated test profiles; no orbit or chase mode. |
| Mobile controls | KEEP + UPDATE | Existing action injection retained. Touch vector now targets the input source; safe-area-aware layout and visible joystick region added. |
| Quality Manager | KEEP + UPDATE | LOW/MEDIUM/HIGH/ULTRA retained. Mapping is Mobile Web / mobile native / Desktop Web / native desktop; LOW keeps 1.0 render scale until mobile hardware validation. |
| Platform Service | KEEP + UPDATE | Web/Android/iOS/Desktop detection retained; added diagnostic platform name. Native orientation call is now Android/iOS-only because Web does not support it. |
| GameState | KEEP | Autoload, catalog loading and fresh-save foundation are 4.7.2 compatible. No balance values were duplicated in GDScript. |
| Shared catalog | KEEP | `shared/game-data/catalog.v1.json` remains source and `godot/data/catalog.v1.json` remains byte-identical. |
| Save Repository | KEEP | `user://profiles`, `FileAccess`, `DirAccess` and JSON remain portable to Web/native targets. Full save migration is out of scope. |
| World scene | REFACTOR | Rudimentary world retained and expanded into Region → Island Group → Island → POI → Local Props proxy hierarchy. |
| Player scene | REPLACE visual / KEEP gameplay | Placeholder BoxMeshes removed. Existing body/collision ownership retained; Kraken is isolated under `VisualRoot`. |
| Export presets | KEEP + UPDATE | Web/Android/iOS retained, missing filters fixed, stale version metadata updated, generated build resources excluded, Windows added. |
| GLB asset pipeline | KEEP + UPDATE | Exact tracked Kraken GLB is used. Godot 4.7.2 import metadata and script UIDs are retained; `.godot` cache and extracted source textures are not committed. |

## Existing foundation confirmed

- Main → World scene boot path and autoload order are valid.
- Gameplay is constrained to `GameplayPlane.WATER_Y` and X/Z.
- Desktop actions preserve WASD, arrow keys, wheel zoom, fire and abilities.
- GL Compatibility remains the only renderer path.
- Web, Android and iOS presets existed before G0.1.
- Kraken asset hash is the tracked `HEAD` blob and size is 21,394,148 bytes.

## Historical versus current truth

The V15/V16 migration documents remain architecture history. Camera/XZ/cross-platform
contracts remain binding; feature status is superseded by
`V20_3_2_FEATURE_MIGRATION_MATRIX.md` and the V20.3.2 web implementation.
