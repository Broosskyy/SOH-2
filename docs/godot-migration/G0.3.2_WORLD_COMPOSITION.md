# G0.3.2 World Composition

## Region source

Azurwacht layout from V20.3.2 `aster_region_factory.gd` — catalog positions preserved (`_catalog(x,y)`), presentation spacing calibrated.

## Density targets (MID zoom)

- Player (center prominence)
- 2–4 NPC ships (neutral + hostile groups)
- 1–3 nearby islands / landmarks
- Hafen Aster harbor POI
- Loot / buoy POIs where catalog defines them
- Substantial open-water lanes

## Island shape variety (temp procedural)

| Shape class | Example island |
| --- | --- |
| Small islet | `glass_reef` |
| Long / narrow | `watch_cliff` |
| Crescent / hook | `crescent_hook` |
| Medium irregular | `sun_rest` |
| Large landmark / harbor | `harbor_aster` |

## Size classes

XS, S, M, L, XL supported via `IslandPresentationProfile.SizeClass` and `_land_height()`.

## Open water

`visual_scale` reduction (0.88 → 0.58) restores navigable ocean between landmarks without inventing new island fields.
