## Summary

G0.3.1 replaces the Android-visible giant cylinder island proxies with footprint-scaled temporary island visuals, recovers V20.3.2 Azurwacht layout data, and introduces the first mockup-aligned HUD/minimap presentation layer while preserving all G0.3 gameplay architecture.

## Giant debug geometry

**REMOVED** from production `VisualRoot`. Root cause: `island_root.gd` always spawned large unlit `CylinderMesh` pairs sized above gameplay footprint. Debug footprints now live in hidden `DebugRoot` (F9 only).
