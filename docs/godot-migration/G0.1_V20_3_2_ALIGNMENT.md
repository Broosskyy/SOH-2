# G0.1 V20.3.2 Alignment

Reference: `d6c4de5` feature state and `e950596` web-build state.
The existing `app/`, `public/` and `web-build/` implementations were not changed.

## Migrated presentation slice

- Exact Kraken GLB instanced under a visual-only root.
- Binding gameplay forward remains `-Z`; source `+Z` correction is the
  profile-owned 180-degree visual yaw, never a movement/heading hack.
- Presentation profile owns scale 52, waterline offset 20.5, visual yaw,
  UI anchor height, safe gap and visual envelope. Values are Godot calibration,
  not a blind copy of current web scale 65 / waterline 22.
- Screen-space name/HP/shield use a 3D `UIAnchor` and native
  `Camera3D.unproject_position()`.
- Compact HUD remains horizontal through continuous 360-degree ship rotation.
- Three fixed naval camera profiles enable direct comparison:
  Perspective Naval (default), Low-FOV Perspective and Orthographic.
- Shared catalog camera values now match the authoritative V20.3.2 Web policy:
  35-degree FOV and 0.55–1.38 zoom. Godot consumes the same limits.
- Eight deterministic QA headings are available without discrete gameplay
  heading states.

## World alignment

The G0.1 proxy test world demonstrates macro-first composition:

`World → Region_Aster → IslandGroup → Island → POI_Harbor → LocalProps`

It contains open water, one small island, one medium island and a harbor/beacon
POI. These are temporary clean proxies, not final island assets.

## Reference interpretation

- The V20.3.2 diagonal Kraken silhouette is the positive baseline.
- The north/south thin-silhouette and status-overlap screenshots are known
  problems, not targets.
- Camera A intentionally sits between classic high naval overview and a lower
  modern 3D presentation.
- Perspective differences remain physically correct; no sprite swaps, fake
  headings or heading-dependent gameplay rotations were introduced.

## Known input-semantic gap

V20.3.2 Web uses click/tap destination navigation and a left joystick for
camera pan. Godot G0.1 uses its touch joystick for direct ship steer/thrust.
Both feed platform-neutral actions, but they are not presentation-equivalent.
G0.2 must choose and document the final mobile navigation model before claiming
input parity.

## Deferred to G0.2

Final camera lock, final waterline/scale approval on target devices, Kraken
texture/LOD optimization, real island assets, final ocean and final HUD polish.
