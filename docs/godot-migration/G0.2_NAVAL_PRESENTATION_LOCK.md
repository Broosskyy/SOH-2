# G0.2 Naval Presentation Lock

Baseline: `134b4b4`. Engine: Godot 4.7.2 using the GL Compatibility renderer.

## Production camera

The production profile is **Perspective Naval**:

| Setting | Locked value |
| --- | ---: |
| Field of view | 35 degrees |
| Height | 560 |
| Back distance | 360 |
| Lateral offset | -58 |
| Target offset | `(0, 12, -52)` |
| Zoom range | 0.55–1.38 |

This perspective profile is the production presentation. Alternate calibration
profiles remain comparison/debug tools and are not production defaults.

## Kraken presentation

| Setting | Locked value |
| --- | ---: |
| Visual scale | 52 |
| Visual yaw | 180 degrees |
| Waterline offset | 20.5 |
| Wake stern point | local `+Z`, 58 |

Gameplay forward remains `-Z`. The 180-degree visual yaw corrects the source
model orientation; it does not change movement or heading semantics.

## HUD calibration

Native LOW/HIGH captures at 1280×720, 1920×1080 and 2400×1080 were generated
and reviewed. QA found the compact HUD too close to the Kraken silhouette at
north/south headings. The presentation values were corrected from
`ui_anchor_height = 59` to `68` and from `gap = 8` to `10`. The corrected
north/south spacing is accepted across the native matrix.

HUD and controls consume the same safe-area definition. They must not maintain
independent inset assumptions.

## Scope of the lock

This document locks the calibrated camera, ship placement, wake origin and HUD
spacing for G0.2. It does not claim Mobile Web, Android or iOS hardware visual
approval. Those targets require the evidence described in
`G0.2_MOBILE_WEB_VALIDATION.md`.
