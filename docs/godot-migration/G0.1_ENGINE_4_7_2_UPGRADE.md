# G0.1 Engine 4.7.2 Upgrade

## Verified toolchain

- Before: Godot 4.3 project feature tag.
- After: `4.7.2.stable.official.ed1daf0bf`.
- Source: official `godotengine/godot-builds` release `4.7.2-stable`.
- Renderer: GL Compatibility retained for Web/mobile portability.
- Export templates: official 4.7.2 Stable templates.

## Tracked migration changes

- `godot/project.godot`
  - feature tag `4.3` → `4.7`;
  - numeric application version `0.1.0`;
  - ETC2/ASTC import enabled for Android/iOS compatibility;
  - renderer and all existing input actions retained.
- `godot/export_presets.cfg`
  - explicit include/exclude filters added;
  - generated `build/**` resources excluded;
  - Android/iOS version metadata aligned to V20.3.2/G0.1;
  - Windows x86_64 preset added.
- Godot 4.7 generated stable `.gd.uid` and asset `.import` metadata. These
  source-side metadata files are reviewed and retained; `.godot/` remains ignored.
- No automatic scene rewrite was accepted blindly. Scene changes are intentional
  G0.1 edits.

## API compatibility review

No breaking replacements were required for:

- `CharacterBody3D.velocity`, `move_and_slide()` and Y rotation;
- `Camera3D` perspective/orthogonal projection, FOV, size and
  `unproject_position()`;
- `CanvasLayer`, `Control`, `ProgressBar`, `WorldEnvironment`,
  `Environment`, `DirectionalLight3D` and `StandardMaterial3D`;
- `FileAccess`, `DirAccess`, `JSON`, autoloads and `DisplayServer`.

One runtime portability correction was required: `screen_set_orientation()` is
unsupported by the Web display server, so the call is restricted to Android/iOS.

## Validation

- Headless editor import: PASS, no parser errors.
- Main scene headless runtime: PASS, no critical null references.
- Native GL Compatibility runtime: PASS.
- Web export: PASS.
- Windows debug export: PASS.
- Android debug APK export: PASS after ETC2/ASTC enablement; no device runtime
  was available.
- iOS preset parse/readiness: PARTIAL (cannot build iOS on Windows).

## Behavior impact

- InputMap behavior is unchanged.
- Gameplay movement remains X/Z with fixed water Y.
- Web is single-threaded and GDExtension-free as before.
- Renderer was not converted to Forward+ or Mobile.
