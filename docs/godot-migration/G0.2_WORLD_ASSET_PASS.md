# G0.2 World Asset Pass

Baseline: `134b4b4`.

## Authored presentation assets

G0.2 uses authored WebP island presentations copied from existing public
assets:

- tropical;
- storm;
- abyss.

The small and medium island scenes use storm/tropical presentations over the
retained 3D proxy landmasses. This improves authored visual identity while
preserving the existing proxy geometry and world composition.

## Asset classification

No authored 3D island or harbor GLBs exist in the reviewed source. Therefore:

- the WebP presentations are authored 2D presentation assets;
- the underlying small/medium landmasses remain 3D proxies;
- the harbor remains a proxy presentation/POI;
- these scenes must not be described as final real 3D island or harbor assets.

The abyss presentation is available as part of the authored presentation set,
but its presence does not change the geometry classification.

## Deferred production work

Final 3D island and harbor delivery still requires authored geometry, materials,
collision/navigation treatment, LODs, target-platform profiling and visual
approval. G0.2 establishes a presentation pass, not completion of that asset
pipeline.
