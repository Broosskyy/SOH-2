# G0.3 Game Unit Architecture

Composition over inheritance:

```
GameUnit (Node3D)
├── UnitIdentity
├── HealthComponent
├── TargetableComponent
├── GameplayRoot / VisualRoot / CollisionRoot / UIAnchor
```

`ShipEntity` extends `CharacterBody3D` with `ShipPresentationProfile` for visual scale, waterline, weapon anchors, and HUD envelope. `PlayerShip` and `NpcShip` share this domain; input stays in `PlayerInputSource` only.

Network boundary: `PlayerRepository` / `WorldRepository` stubs — no SDK coupling.
