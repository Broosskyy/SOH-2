# G0.5.6 Master Composition Analysis

**MASTER VISUAL REFERENCE IS RESOLUTION-INDEPENDENT.**

The Master mockup defines semantic hierarchy, grouping, and relative prominence — not pixel coordinates, viewport size, or aspect ratio.

## Semantic layout regions

### TOP LEFT — Player identity
- Portrait / avatar (compact on phone)
- Player name (primary, gold)
- Level
- Guild tag

### PROFILE SECONDARY ROW — Currencies
- Gold (icon + value)
- XP / swords (icon + value)
- Diamonds (icon + value)
- Compact strip; no tall cards

### TOP STATUS — Vital bars
- EXP with current/max
- RUMPF (hull) with current/max
- SCHUTZ (shield) with current/max
- Thin horizontal bars; adjacent to profile, never overlapping

### TOP NAVIGATION — Single band
- Ships, Shipyard, Events, Quests, Shop, Guild, Chat, Achievements, Logbook, Rankings, Bonus, Menu
- Shares top band with profile/status/minimap
- Phone: priority entries + Menu overflow

### LEFT UPPER — Active mission
- AKTIVE MISSION heading
- Mission title, objective, progress bar
- Below profile column only (does not extend under status)

### LEFT CENTER — Zoom / camera
- +, MID, -, SHIP recenter
- Secondary to mission; grouped vertically

### BOTTOM LEFT — Chat
- Global / Guild / System tabs
- Few preview lines on phone
- Secondary panel

### TOP RIGHT — Minimap + utilities
- Circular minimap (prominent but not dominant)
- FS / utility controls

### BOTTOM CENTER — Consumables
- Four circular items (OIL, POT, BMB, H2O)
- Smaller than FEUER; above bottom edge, outside player-safe area

### BOTTOM RIGHT — Combat cluster
- FEUER: largest interactive control
- Abilities: smaller arc above/left
- Utilities: ammo, shield, repair — smaller still

### CENTER — Gameplay safe area
- Player ship + floating HUD
- World entities
- No persistent HUD intrusion

### WORLD — Screen-space labels
- Player nameplate: most readable
- NPC name/level: smaller
- Island / loot / POI: secondary tier

## Semantic relationships

| Element | Relationship |
| --- | --- |
| Profile | Compact identity block; left anchor |
| Status | Adjacent right of profile; same top band height |
| Navigation | Fills space between status and minimap |
| Mission | Below profile column only |
| Minimap | Top-right; diameter from short-edge clamp |
| Chat | Bottom-left; compact height |
| Consumables | Bottom-center; below player-safe region |
| Combat | Bottom-right; FEUER dominates cluster |
| Center | World-first; UI at edges |

## Phone landscape recomposition (~754×297)

Top band: `[PROFILE][CURRENCY strip][STATUS][NAV……][MINIMAP]`

Mission stacks under profile column. Zoom below mission. Chat bottom-left. Consumables bottom-center. Combat bottom-right with safe edge margins.
