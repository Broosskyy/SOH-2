# G0.3.2 Mobile HUD

## Problem (Group A)

Desktop-sized fonts and panels rendered on Android landscape without responsive scaling — mission panel, top bar, and minimap unreadable.

## Solution — `HudLayout`

- `scale_factor(viewport)` — mobile 1.45–2.25× based on short edge / 1080
- `font_size()`, `touch_size()`, `panel_margin()` — derived helpers
- `is_mobile_layout()` — `PlatformService.mobile` or width < 960 / short edge < 620

## GameplayHud mobile behavior

| Element | Mobile |
| --- | --- |
| Top bar (captain, RUMPF, SCHUTZ, currency) | Scaled, visible |
| Mission panel | Scaled, readable |
| Nav row (WERFT/MISSION/SEEKARTE/GESCHÄFT) | Hidden |
| Combat cluster (FEUER, abilities) | Hidden (G0.4) |
| Region label | Hidden |

## Minimap

Mobile size ~220×138× scale factor; `MinimapCanvas` `_draw()` for markers.

## Mobile controls — single owner

`MobileControls` (layer): KAMERA joystick + pinch zoom only.

Tap water → ship navigation (unchanged `PlayerInputSource`).

## Floating HUD

`FloatingStatusHud` scales panel and fonts via `HudLayout` each frame.

## QA captures

`15_MOBILE_HUD`, `16_MOBILE_CONTROLS`.

## Touch targets

`HudLayout.MIN_TOUCH_PX = 48` minimum for critical controls.
