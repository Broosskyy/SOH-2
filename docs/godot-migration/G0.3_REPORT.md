# G0.3 — World Domain + Game Unit Migration

**Status:** PASS (pending real Android hardware retest)  
**Base commit:** `46e9281`  
**Engine:** Godot 4.7.2, GL Compatibility  
**Build:** `0.3.0`

## Summary

G0.3 migrates the V20.3.2 world domain into the Godot client using composition-first architecture:

- **GameUnit / ShipEntity** — player and NPC ships share movement, health, targeting, and presentation boundaries
- **RegionDefinition + RegionRuntime** — data-driven Azurwacht (`aster_g03`) region
- **IslandEntity** — proxy gameplay geometry (SMALL / MEDIUM / LANDMARK); G0.2 WebP billboards removed from production
- **Harbor + POI** — approach/interaction state, world labels
- **NPC spawner** — neutral `Handelskonvoi`, hostile `Scherben-Plünderer` with patrol + detection hooks
- **TargetingSystem** — selection boundary only; combat deferred to G0.4
- **NavigationController** — tap navigation with island blocking

## G0.2 WebP Island Issue

**Root cause:** `Sprite3D` WebP billboards in `World.tscn` caused severe vertical stretching on Android Chrome WebGL.

**Resolution:** Removed from production presentation. WebPs remain as design references under `godot/assets/world/islands/`. Islands use **PROXY GAMEPLAY GEOMETRY** via `IslandRoot`.
