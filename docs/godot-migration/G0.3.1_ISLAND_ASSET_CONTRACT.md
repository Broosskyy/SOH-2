# G0.3.1 Island Asset Contract

## Profile: `IslandPresentationProfile`

| Field | Purpose |
| --- | --- |
| `island_id` | Stable key / scene name |
| `size_class` | XS … LANDMARK |
| `shape_class` | Silhouette family (20+ enums) |
| `biome` | Material palette |
| `visual_scene` | Future authored GLB scene |
| `visual_scale` | Multiplier on gameplay footprint |
| `waterline_offset` | Y placement |
| `gameplay_radius_x/z` | Navigation + blocking |
| `navigation_block_radius` | `blocks_point()` |
| `collision_profile` | ellipse / future mesh id |
| `world_label_height` | Label anchor |
| `harbor_anchor`, `poi_anchors`, socket arrays | Attachment points |
| `lod_policy`, `lod_distances` | Distance tiers |
| `quality_policy` | AUTO / LOW / HIGH |
| `use_proxy_geometry` | Temp builder gate |

## Three-layer concept (future GLB)

1. **Island main** — land mass  
2. **Coast transition** — shore ring / foam alignment  
3. **Underwater base** — rock volume below waterline  

`IslandVisualBuilder` implements all three in inexpensive form today.

## Drop-in path

`godot/assets/world/islands/<island_id>/` + `manifest.json`

## Debug separation

Gameplay footprint debug mesh lives in `DebugRoot`, toggled F9 only. Never visible in normal play.
