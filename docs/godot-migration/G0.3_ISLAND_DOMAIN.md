# G0.3 Island Domain

`IslandEntity` separates gameplay footprint from `VisualRoot`.

`IslandPresentationProfile` defines size class (SMALL / MEDIUM / LANDMARK), navigation block radii, label height, and `use_proxy_geometry`.

`IslandRoot` builds **PROXY GAMEPLAY GEOMETRY** (cylinder landmasses). Final GLB drop-in contract: assign profile → attach to `VisualRoot` → calibrate scale/waterline/navigation.

G0.2 WebP `Sprite3D` presentation removed — unsuitable for Android WebGL production.
