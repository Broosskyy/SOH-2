# G0.3 NPC System

```
NpcSpawnGroup → NpcSpawner → NpcShip
                    ↓
            NpcBehaviourProfile (IDLE / PATROL)
```

First region: neutral `Handelskonvoi`, hostile `Scherben-Plünderer` with patrol routes and `detection_range` awareness (no chase/attack combat).

NPCs are full `ShipEntity` instances with proxy hull visuals — not decorative props.
