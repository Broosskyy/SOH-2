# G0.3.3 Asset Transition

## Policy change

Procedural islands = **PROCEDURAL_FALLBACK only**. No further procedural art investment.

## Drop-in contract

`IslandEntity` → `IslandGameplayRoot` / `IslandVisualRoot` / `IslandPresentationProfile`

Required manifest fields: `godot/data/island_asset_manifest.json`

- visual_scene (GLB)
- scale, waterline, bounds
- size_class, shape_class, biome
- collision/navigation footprint
- label anchor, harbor/loot/boss sockets
- LOD metadata, quality policy

## Asset status enum

`IslandPresentationProfile.AssetStatus`: FINAL_ASSET, TEMP_PRODUCTION_SAFE, PROCEDURAL_FALLBACK, MISSING

## NPC / harbor

Replace via `NpcShipVisualRoot` / `HarborVisualRoot` without gameplay rewrite.
