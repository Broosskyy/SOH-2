# G0.3 Region / World System

```
RegionDefinition (Resource)
    ↓
RegionRuntime.load_from_definition()
    ↓
Islands + Harbors + POIs + NpcSpawner
```

First region: `AsterRegionFactory.create()` → `aster_g03` (Azurwacht).

`World.tscn` is bootstrap only (ocean, sun, player, camera, HUD). Region content is data-driven.

Future: multiple regions, transitions via `RegionExit` boundary (not implemented in G0.3).
