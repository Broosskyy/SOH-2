# G0.2 Input Decision

Baseline: `134b4b4`.

## Final platform semantics

The production model is hybrid:

- **Mobile/touch:** tap a destination for ship movement, use the left joystick
  to pan the camera, and pinch to zoom.
- **Desktop:** WASD provides direct ship steering.

Both paths must use platform-neutral commands while preserving these different
interaction semantics. The left mobile joystick is not a direct-steer control.

## Navigation scope

Tap navigation is basic planar destination navigation on the water plane. It
provides destination selection and planar travel only. G0.2 does **not** include
full pathfinding, obstacle routing, collision-aware route planning, combat
movement, target pursuit or tactical AI. UI and status text must not imply
those systems exist.

## Safe areas and gesture ownership

HUD and controls use one shared safe-area model. Touch controls must remain
inside the same usable rectangle as HUD content.

Gesture ownership is:

- tap on navigable world space: set destination;
- drag on the left camera joystick: pan camera;
- two-finger pinch: zoom;
- touches captured by HUD/control UI: do not create world destinations.

Physical-device validation is still required for gesture conflicts, cutouts,
orientation changes and browser-native gesture interference. The interaction
decision is final; hardware validation is not.
