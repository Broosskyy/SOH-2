# G0.1 Known Limitations

- Mobile Web is not signed off on real Android/iOS browser hardware. Chromium
  touch emulation reports a live, error-free Godot engine but cannot provide a
  reliable WebGL screenshot on this workstation.
- Kraken has no LODs. The imported Kraken contribution is 17,467,686 bytes and
  dominates the 17,582,744-byte Web PCK.
- The source GLB embeds 2048² base-color and 4096² metallic/roughness textures.
  Estimated uncompressed RGBA mipmapped footprint is about 106.7 MiB. Format,
  channel packing and mobile downsizing require visual A/B approval.
- Default GLB import generates adjacent baked PNG extraction files. They are
  reproducible and ignored; reviewed `.import` settings are retained.
- Kraken's dark source palette remains conservative under GL Compatibility.
  G0.1 applies only a small runtime albedo lift; final material grading is G0.2.
- Camera A, scale 52 and waterline 20.5 are first-pass calibrations, not final
  production locks. Eight-way captures show readable continuous rotation, but
  north/south remains naturally narrower than broadside.
- Island and harbor geometry are test proxies without gameplay collision,
  navigation data, LODs or final materials.
- Ocean motion is still the lightweight migration placeholder, not a final
  shader.
- Android APK was exported but not installed/run on a device. The G0.1 AD icon
  is a functional placeholder, not final brand artwork.
- iOS cannot be exported or signed on the Windows host.
- Combat, NPC AI, monsters, missions, progression, economy, complete save
  migration and final HUD remain outside G0.1.
