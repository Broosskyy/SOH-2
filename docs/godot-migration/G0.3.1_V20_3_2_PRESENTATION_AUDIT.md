## Root cause — Group A hardware failure

G0.3 rendered oversized `CylinderMesh` pairs directly in `VisualRoot` with no materials. These dominated the camera frame on Android and read as debug slabs. G0.3.1 replaces them with footprint-scaled `IslandVisualBuilder` meshes and moves debug footprints to hidden `DebugRoot`.
