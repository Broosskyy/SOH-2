# G0.3.2 Island Visual Recovery

## Failure

G0.3.1 Android screenshot showed radial fan / star polygon island silhouettes — not readable as islands.

## Root cause

`IslandVisualBuilder._make_deformed_disc()` used a center-top vertex with triangle fan triangulation and inconsistent side-wall vertex ordering, producing visible radial spokes on GLES3 Mobile Web.

## Fix

`_make_solid_island_mesh()`:

1. Deformed perimeter ring (top + bottom) with seeded wobble
2. Top surface: perimeter triangulation (no elevated center vertex)
3. Bottom surface: reversed winding
4. Side walls: quad strips between rings
5. `generate_normals()` for coherent shading

## Coast treatment

- Shallow ring mesh (sand tint)
- Inner foam ring (alpha)
- Cliff rock shell under land cap

## Shape variety

Procedural dressing per `ShapeClass`: crescent hook, twin lobe, tall cliff, long ridge, harbor dock extension, palm dressing (non-LOW).

## Quality bar (temp islands)

- Irregular coastline
- Filled terrain surface
- Visible elevation + cliff
- Clear waterline
- Non-radial silhouette from gameplay distance
- Replaceable via `IslandVisualRoot` without gameplay rewrite

## Scale

Region `visual_scale = 0.58` (was 0.88) — islands no longer dominate MID frame.

## Tests

`godot-g0.3.2-presentation.test.mjs` — mesh validity, shape classes, no `center_top` / `_make_deformed_disc`.
