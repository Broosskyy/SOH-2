# G0.3 World UI

- **Player HUD:** existing `FloatingStatusHud` (Captain Rowan, HP/shield)
- **World labels:** `WorldLabelService` projects island, harbor, POI, and NPC names
- **Target reticle:** `TargetReticle` follows `TargetingSystem.current_target`
- **Debug overlay:** G0.3 metrics (region, NPC counts, harbor state, navigation, target)

Mobile landscape: `World._apply_viewport_policy()` uses `CONTENT_SCALE_ASPECT_EXPAND` on mobile Web.
