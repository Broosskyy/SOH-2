# M185 — Menu Content Clarity

M185 turns the M183/M184 navigation foundation into readable player-facing information. Existing runtime state is summarized in compact cards instead of long unstructured text blocks.

## Delivered

- Harbor/sea location context on relevant pages.
- Home card for the next real objective.
- Bonusmap cards for eligibility, harbor requirement, fragments, active wave, completions and Gold pity.
- Quest Log groups for Core/Story, Region, Daily/Weekly, Hunter, Guild and Event.
- Daily and Weekly claims are disabled until the same runtime completion checks used by the mutation path succeed.
- Progression card separates Pirate Level, Map Level, Ship Level, Fame, Honor and Battle Rank.
- Equipment card summarizes active cannon, ammunition, deck and cannon capacity.
- Event card shows phase, currency and world meter; inactive events are shown honestly.
- Guild and Rankings pages explain the production authority boundary without fabricating players, wars or scores.

## Preserved

- Seekarte-first play and all Masterkonzept V3.8 mobile controls.
- M183 Command Deck hierarchy and M184 single-owner panel routing.
- Transactional bonusmap entry and refund protection.
- Existing reward, purchase, guild, ranking, payment, admin and LiveOps authority boundaries.

Native Godot 4.7.2 and real-device acceptance remain deferred until the engine/device environment is available.
