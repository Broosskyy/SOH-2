# M153 · W5 Classes 51–60 GLB/LOD Production Batch

M153 converts the first late-fleet wave from reserved addresses into real, replaceable clean-room GLB placeholders. It preserves V3.8 meta systems, the three starter ships, 100 regular classes and separate Prestige P1–P5.

## Implemented

- Ten visually distinct W5 models for classes 51–60.
- Three physical GLB files per class: LOD0, LOD1 and LOD2.
- Thirty valid GLTF 2 binary files with thirty unique hashes.
- Ten stable sockets in every LOD: four broadside ports, bow weapon, two mast sockets, sail socket, wake anchor and nameplate anchor.
- Deliberate macro-silhouette changes: spear, hook, asymmetric blade, outriggers, crescent, armored ribs, stern tower, wedge ram, mortar terrace and royal double gallery.
- Platform-aware runtime selection: desktop sea map uses LOD1, mobile/Web sea map uses LOD2 and desktop hero inspection can use LOD0.
- A QA scene compares all ten classes in desktop-hero and mobile-map LODs.
- Admin overlay reports complete LOD sets, physical GLB count and socket coverage.

## Honest asset status

These files are functional, visual-only production placeholders. They are not final outsourced or hand-authored art and never count as final GLB completion. A final model can replace each stable path while retaining socket names. Collision, movement, damage, progression, wake, foam and combat VFX remain outside the model.
