# M73 — PL1–5 Quest Presentation, Minimap POIs & World Dressing

M73 deepens the existing beginner progression without changing its tuning or inventing backend authority.

- Added a presentation-only PL1–5 briefing layer around the existing VoyageProgress trial system.
- Active beginner trials now expose one primary sink/loot/dock objective in a compact phone-first HUD strip.
- Existing BeginnerRules goals/rewards remain untouched.
- M72 POIs now project onto the minimap with a strict nearest-six density cap; world markers remain capped separately.
- Added density-aware visual island dressing using stable palm/rock/driftwood slots. Dressing never owns collision, rewards or quest state.
- Added six more final-art replacement slots for single palms, small rocks, shallow reef, wreck mast, wreck anchor and barrel cluster.
- Added mobile world-readability budgets and an M73 production wave.
- Asset Preview includes an M73 DRESSING filter.
