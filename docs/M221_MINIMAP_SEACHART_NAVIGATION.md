# M221 — Minimap / Seekarte / Navigation

M221 converges the upper-right minimap with the existing M219/M220 world-marker and Tap-to-Sail guidance systems. The five gameplay master references remain the visual authority: the minimap is a stronger circular nautical anchor, while the sea-chart itself remains visually dominant.

The minimap is north-up and now exposes the player's ship heading explicitly. Selected combat targets, tracked objectives and Admirals/Bosses receive stronger rings rather than large labels. The active Tap-to-Sail destination and the already-existing M192 land-detour steering bend may be shown as a restrained dashed course. This is presentation only: M192/M220 remain route authority and the captain's final destination is unchanged.

No world target is fabricated for navigation. Mobile, web and desktop use the same map, actors, POIs and route state; only minimap/HUD sizing responds to the device profile.
