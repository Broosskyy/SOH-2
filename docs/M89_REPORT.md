# M89 — Guild Islands from Map Level 2 + Early Interaction/Defense Foundation

The new binding progression rule is implemented as an early-world source contract: Guild Islands can appear from map level 2.

The existing Guild Bible remains authoritative for structure: oblique sea-map/harbor presentation, modular Island Base + Harbor/Facilities/Defense/Decorations/Event layers, tower Target/Range/Reload/DamageDefinition, no broadside-angle damage, and no permanent deletion of guild progression after siege loss.

M89 deliberately does not fake a multiplayer backend. It creates a deterministic local visual/interaction preview with stable GLB/UI slots for island base, dock, hall, warehouse, repair station and early cannon/chain towers. Proximity interaction rows expose Dock/Guild/Defense/Facilities as presentation contracts. Membership, ownership, treasury/vault, wars, tower damage, upgrades and siege state remain explicitly server-authoritative future systems.

This reconciles the older Bible progression text that placed deeper island/facility progression later: discovery/world presence is now from map level 2, while ownership/economy/war authority and advanced tiers still unlock progressively when the real guild backend exists.
