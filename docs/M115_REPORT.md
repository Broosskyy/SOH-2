# M115 — PL26–30 Abyss Veteran Band

M115 physically extends the 6×6 world without moving PL1–25: levels 26–30 occupy the unused right-side column and remain contiguous from PL25.

Progression now has a PL26–30 catalog with XP + Admiral + Hunter + regional objectives and a PL30 Pirate Trial focused on Abyss/Hunter/Corruption. XP alone never unlocks the band.

Abyss Corruption is implemented as an explicit opt-in local runtime. Players must deliberately retain it. Higher bands expose increasing risk/reward multipliers; the harbor can cleanse it completely. It is not a hidden mandatory debuff.

Credited PL26+ combat grants Abyss materials and fragments. Abyss Bonusmap has an eligibility/entry/reward contract at PL26+ and replacement-ready UI/world slots; the final isolated bonus-map scene loop remains pending.

New stable replacement slots cover Abyss NPC fleet, Admiral, Drowned Beast/Abyss monsters, five island identities, harbor and UI.

Native Godot 4.7.2/mobile/web/desktop parser/runtime QA remains pending.
