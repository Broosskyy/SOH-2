Truth boundary: the Gold loop currently consumes qualified open-sea sinks rather than switching to a fully isolated bonus-map scene. This is functional progression state, but not yet the final instanced-map implementation. Build modifiers are stored on the ship as runtime metadata; deeper stat consumption is a next-step integration. No server authority is claimed.
