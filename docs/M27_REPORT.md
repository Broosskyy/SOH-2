# M27 Report — Command Deck, Daily/Weekly and Event Hub

M27 continues the project-owned visual mockup as the visual master while deepening the modern persistent naval-combat product shell.

## Implemented

- Card-based responsive Command Deck for Events, Quests, Market, Guild, Chat, Achievements, Rankings, Bonus, Group and Captain Menu.
- Persistent Daily objectives: 5 sinks, 6 salvage pickups, 3 harbor visits.
- Persistent Weekly objectives: 24 sinks, 20 salvage pickups, 10 harbor visits.
- Claimable Daily reward: 450 Gold / 180 EXP.
- Claimable Weekly reward: 1800 Gold / 700 EXP.
- Event points are generated by sink/loot/dock gameplay records and surfaced in the Events hub.
- Pirate Hunt, Leviathan Hunt and Admiral Alert cards establish the event presentation layer without inventing online population data.
- Five-zone mobile bottom navigation keeps core menus reachable in portrait/compact layouts.
- Opening the menu remains input-safe: sailing/navigation is cancelled and world touches do not leak through.

## Preservation

M25 encounter state machines, boss/monster work, M24 tactical combat, M23 rank/loot presentation and existing shipyard/arsenal/world map flows remain in place.
