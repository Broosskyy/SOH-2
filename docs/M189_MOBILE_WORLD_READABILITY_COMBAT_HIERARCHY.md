# M189 — Mobile World Readability & Combat Hierarchy

M189 is a presentation-focused continuation of the M180–M188 repair line and follows the gameplay master references: the sea remains the dominant visual surface, the permanent HUD stays on the edges, the primary attack remains bottom-right, and temporary world guidance must never cover permanent controls.

## Repairs

- The tracked-objective marker remains the highest-priority world cue, but off-screen edge placement now searches nearby candidates that do not intersect reserved HUD geometry.
- The contextual Target control visibly reads `HAFEN` only while a real nearby port exists. At sea it reads `ZIEL` and retains target cycling.
- Safe-zone messaging no longer says or implies that the global Shipyard requires docking. It refers only to local harbor interaction.
- The current Nautical HUD no longer adds the old rectangular mobile action rail on top of the global shipyard overlay. The circular combat/action hierarchy remains the canonical gameplay control language.
- The existing minimap tracked-objective ring, Tap-to-Sail, camera-only wheel, M186 tracking and M187/M188 harbor boundary remain intact.

No economy, entitlement, reward or server authority changes are introduced.
