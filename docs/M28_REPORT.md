# M28 — Fleet Command + Event Loop

M28 keeps the project mockup as the visual master and expands the modern naval MMO-like loop.

- Persistent 100/250/500 event milestones with claimable rewards.
- Quest-chain stage progression driven by real gameplay actions.
- Event hub ties pirate hunt, Leviathan hunt and Admiral alert to player progress.
- Harbor market presentation now explicitly communicates port-only purchases.
- M25-M27 combat, encounter, loot, daily/weekly and cross-platform foundations remain intact.
