# M99 — Guild Island Mobile UX + Modular Fortification Pass

M99 turns the map-level-2 guild island UI into a more usable touch/desktop/gamepad surface and improves the island silhouette.

- Six dedicated, replaceable guild UI icons are active for docking, guild hall, defense, facilities, range preview and focus.
- Touch and mouse can select individual tower/facility detail rows. Those hits are processed before Tap-to-Sail.
- Existing previous/next gamepad/keyboard focus cycling remains active while a guild detail panel is open.
- The island gains two straight wall segments, two corner segments, one harbor gate and one watch platform. These are visual-only modular fortification slots with no collision, siege or persistence authority.
- Tower range preview and reversible tower-state controls from M98 are now actually exposed in the Admin overlay.
- No marker budget was increased and fortification/range fallback visuals cast no shadows.
- Five additional permanent-world slots are prepared for long/split/small-cliff islands and pirate-harbor variants without spawning extra dressing yet.

Ownership, treasury, vault, war, conquest and persistent tower/facility damage remain future server-authoritative systems.
