# Historischer M32-Vorschlag für die nächste native Abnahme

M33 wurde auf Nutzerwunsch als Asset-/Platzhalter-Durchgang umgesetzt, siehe
M33_REPORT.md. Die folgenden Geräte-, Grafik- und Gameplay-Abnahmen bleiben offen;
aktueller nächster Vorschlag: M34_NEXT_STEPS.md.

1. Zielengine 4.7.2 bereitstellen/verifizieren. Keine Zielengine-Abnahme aus 4.5.1 ableiten.
2. Anfängerphase tatsächlich durchspielen: kleines Schiff → Clipper → Chalupa → Kartenlevel 6.
   Gold, Munition, Kampfdauer, Rückfahrten ohne Hafen, Sinken und Save/Load messen.
   Die vorläufigen Freischalt-/Auftragswerte anhand dieses Durchlaufs abstimmen.
3. Echte Laufzeitbilder von See, Hafen, Startseite, Kartenfortschritt, Arsenal und
   Systemeinstellungen mit dem Mockup vergleichen. Platzhalterqualität transparent lassen.
4. Android/iOS-Touch, Safe Areas, Lesbarkeit und Play-Erreichbarkeit sowie Windows/macOS prüfen.
   Web bleibt nur Preview.
5. Tap-to-Sail um sichere Hindernisrouten erweitern; visuelle Waffenrückmeldung prüfen.
6. GPU/FPS/Drawcalls/Texturkosten auf echten Geräten messen und Qualitätsstufen abstimmen.

Elite-/Hauptdesignreihe separat spezifizieren: Erwerbswege, eigene Schiffslevel, GLB-Verweise,
Balance. Nicht mit den drei Anfängerdesigns gleichsetzen.
Online/Crossplay benötigt einen eigenen Server-Arbeitsabschnitt.
