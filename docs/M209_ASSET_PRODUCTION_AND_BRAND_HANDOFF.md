# M209 — Asset Production + Brand Handoff

M209 makes **Abyssal Dominion** the current player-facing working title. **VAELTIDE** remains reserved as the alternative brand. Historical reconstruction evidence may still contain SeeFight 3D; those technical/history references are intentionally not mass-renamed.

The source now contains a 20-sheet authored 2D production catalog. Every generation sheet contains at most eight assets, uses transparent-background/spacing rules, and is intended to be cut into individual source masters before optional runtime atlas packing. Ships, islands and monsters remain individual world assets; concept sheets are allowed only as production references.

Gameplay, collision, navigation, balance and cross-platform world parity are unchanged. Native Godot/device QA remains required.
