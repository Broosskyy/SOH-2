# M229 — Encounter Formations & Territories

M229 builds on M228's living-sea layer without increasing runtime population. Existing encounter slots receive a semantic formation read (column, wedge, arc, line or screen), formation slot, group role and danger priority. These values are presentation/content hooks, not a new movement, collision, spawn or combat authority.

Ordinary patrols remain regional lane encounters, monsters remain territory encounters and admirals remain command/staging encounters. Elite rank is exposed as a stronger danger read. Event-zone readiness is metadata only; existing event/content runtime remains authoritative.

The M213/M214 high/wide master camera, large readable sea gaps, safe travel corridors and identical Mobile/Web/Desktop world remain locked.
