# M41 — Action Items + Mobile Combat Status

M41 expands the early combat arsenal with original Abyssal Dominion Action Items and makes their runtime state readable on mobile.

Functional local-prototype items: Emergency Planks, Storm Sail, Abyssal Veil, Storm Bolt, Infernal Barrel, Crystal Barrier, Armor Corrosive, Repair Blocker, Leviathan Hook and Recall Compass.

Rules:
- individual cooldowns and inventory charges;
- target/range checks for hostile and monster items;
- offensive items break Abyssal Veil;
- temporary barrier absorbs damage before shield/hull layers;
- Repair Blocker prevents normal repair for its active duration;
- Leviathan Hook validates monster targets;
- Recall Compass requires no hostile target and recalls to the last respawn/harbor checkpoint;
- no broadside/angle damage.

Mobile HUD:
- Items picker now contains the expanded action-item set;
- cooldown remaining is displayed directly on item cards;
- active VEIL/BARRIER/REPAIR BLOCK/ammo status effects receive compact status chips;
- picker remains responsive one/two-column rather than adding a permanent 20-button hotbar.

No native Godot 4.7.2 executable was available in this environment. Static contract/source validation only.
