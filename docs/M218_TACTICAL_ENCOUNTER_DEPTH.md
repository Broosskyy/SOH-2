# M218 — Tactical Encounter Depth, Boss Readability & Loot Collectability

M218 continues from M217 without changing the five gameplay master references or the M213/M214 camera/world composition. Enemy ships now expose readable tactical states (PURSUE, ALIGN, BROADSIDE, RECOVER, KITE, RETURN) so engagements are less like a binary chase loop. The post-shot RECOVER state does not modify weapon reload authority.

Admiral/boss phase changes expose a short M218 phase-shift presentation state. Sink presentation is classified as normal, elite, admiral or monster for later authored VFX replacement. Boss salvage and the repair cache are spaced farther apart and tagged as a pickup cluster so they remain visually separable at the master-reference zoom. Reward amounts and pickup radius are unchanged.

Mobile, web and desktop keep identical combat/world logic. Native Godot/device visual QA is still required.
