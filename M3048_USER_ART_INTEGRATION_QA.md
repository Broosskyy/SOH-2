- The production game scene `scenes/classic/classic_sea_map.tscn` now uses `scripts/classic/m3048_user_ship_variants.gd`, extending all verified M304.7 HP/sails fixes and M304.6 instant click-to-sail behavior.

- Each actor's base `ships/*.png` is a **single original, intact source image**. Cosmetic `ship_effect_variants/*_cosmetic.png` is selected via the actual settings button, independent of HP, damage, collision and steering.

## Important visual limitations and next necessary work

1. The selected user images have 3/4-oblique perspective. They are not 8/16/32 direction sprite sheets. Rotating a single image is a **temporary visual compromise**. Requires consistent 8 or 16 directions (or fully textured 3D models) for smooth SeaFight-like turning.
2. The ~300px-per-ship crop is alpha-keyed from source sheet backgrounds; fine rigging and glow may show clipping/halos. Final production artwork should be rendered separately at higher resolution with true alpha.
3. Only 3 inherited ammunition mechanics are active; concept pictures for additional shells / buffs / traps / bosses are not represented as implemented systems.
4. The current Android test APK still uses separate private SeaBattles/SeaOfBones reference sprites (for private testing, not public release). Public release requires owned/licensed artwork.
5. On Android, copying a folder to app-private `user://abyssal_user_art/` is not convenient. Build an Android-compatible system file-picker / ZIP importer or integrate cleared assets into an APK with stable signing.
6. Existing enemy wrecks sink with 0 HP and disappear; the supplied wreck reference sheet has not yet been made into runtime wreck actors. Correct next milestone: only instantiate wreck actors at 0 HP, after an explicit sink event. Never replace any live ship's texture with wreck art.
7. The new images cover future NPC categories, 100 ship designs, loot, islands, combat traps and effects. Separate catalogs and actual game logic are future tasks—not silently claimed as done.
