# Recovered test assets

These files were recovered from the user-supplied SeeFight 3D Unity builds for private reconstruction and interoperability testing.

Unlike the older `reference_only` directory, the `m8` subset is intentionally loaded by test runtime exports so the recovered ships, islands, harbor objects, water textures and sounds can be evaluated on Web, Android, iOS and Desktop.

This directory does not establish redistribution or commercial-use rights. Replace it with owned or properly licensed production assets before publishing the project publicly.
