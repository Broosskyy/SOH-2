# P0 replacement folder

Replace the corresponding `.glb` file while keeping its filename unchanged. No script or content ID needs to change.

Requirements: visual-only scene, +Y up, +Z forward, meters, waterline at Y=0, no collision or gameplay scripts. The Godot wrapper owns weapons, sockets, collision, selection, health, movement and input.

Production order: three starter ships, five PL1-5 NPC ships, Haven's Reach, three P0 island silhouettes and the first monster. Validate the result at mobile gameplay zoom before marking a slot complete.
